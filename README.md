# Machine_Learning_Portfolio

## Project overview
This repository contains the Machine Learning Portfolio project using the UCI Air Quality dataset.
The project follows a structured machine learning workflow, including data understanding, data 
quality assessment, preprocessing, baseline modelling, and model evaluation.
The notebooks document the individual steps, methodological decisions, and results.


## Dataset
The project uses the UCI Air Quality dataset, which contains hourly measurements from air quality
sensors and reference analysers.
Dataset source:
[UCI Air Quality Dataset](https://archive.ics.uci.edu/dataset/360/air+quality)


## Project structure
The project is organised into Jupyter notebooks covering different stages of the machine learning workflow.
Each notebook contains explanations, code, and relevant outputs to make the analysis reproducible and understandable.


## Setup
Python version: 3.14.3

The required Python dependencies are listed in
`requirements.txt` and can be installed using:

```bash
pip install -r requirements.txt
```

This notebooks can be executed in numerical order (01, 02, 03) using Jupyter Notebook or Visual Studio Code. Download AirQualityUCI.csv from the dataset source above and place it in the data/folder.
